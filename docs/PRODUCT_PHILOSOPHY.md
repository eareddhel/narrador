# ¿Qué es un proyecto?

En Narrador Studio, un proyecto es el contenedor principal de una narración.

No representa únicamente un nombre o una carpeta.

Representa todo el trabajo necesario para planificar, producir, revisar y exportar una narración completa.

Todo elemento importante de la aplicación pertenece a un proyecto.

## Todo vive dentro de un proyecto

Un proyecto agrupa progresivamente:

- Información general.
- Secciones del guion.
- Narraciones generadas.
- Exportaciones.
- Configuración específica.
- Metadatos de producción.

El proyecto constituye la unidad principal de trabajo dentro de Narrador Studio.

## Lo que un proyecto no es

Un proyecto no es una carpeta del sistema operativo.

No es únicamente un documento.

No es una colección de archivos de audio.

Es una unidad de producción que reúne todos los recursos necesarios para crear una narración.

## Evolución

La primera versión de un proyecto contiene:

- nombre;
- descripción;
- estado;
- fechas.

Las siguientes versiones incorporarán:

- secciones;
- voces;
- narraciones;
- exportaciones;
- configuración específica;
- historial de producción.

La estructura crecerá sin modificar el concepto fundamental: un proyecto sigue siendo el contenedor raíz de todo el trabajo relacionado con una narración.
## El proyecto como unidad de trabajo

### Definición

En Narrador Studio, un proyecto representa una narración completa.

No es solamente un nombre.

No es una carpeta.

No es una colección de archivos.

Es el espacio de trabajo donde vive todo el proceso creativo.

Todo elemento relevante pertenece siempre a un proyecto.

### Contenedor raíz

Un proyecto agrupa progresivamente:

- información general;
- secciones;
- narraciones;
- exportaciones;
- configuración específica;
- metadatos de producción.

Toda funcionalidad futura debe integrarse dentro de un proyecto.

### Flujo de trabajo

El Dashboard no constituye el espacio principal de trabajo.

Su función es:

- mostrar proyectos;
- crear nuevos proyectos;
- permitir seleccionar un proyecto existente.

El trabajo real ocurre dentro del proyecto.

### Creación

Crear un proyecto debe ser una operación rápida.

La primera versión solicitará únicamente:

- nombre;
- descripción.

No solicitar:

- voz;
- idioma;
- motor TTS;
- configuraciones avanzadas;
- parámetros de exportación.

Todo eso pertenece al proyecto una vez creado.

### Después de crear

Una vez creado correctamente un proyecto:

No se vuelve al Dashboard.

La aplicación redirige automáticamente al proyecto recién creado.

La creación finaliza cuando comienza el trabajo.

### Principio

> Crear un proyecto debe tomar menos de treinta segundos.

## La acción termina donde comienza el trabajo

Narrador Studio está diseñado para mantener el flujo creativo del usuario.

Cada acción debe conducir inmediatamente al lugar donde esa acción cobra sentido.

La aplicación evita pantallas intermedias, confirmaciones innecesarias o retornos al punto de partida cuando el siguiente paso natural ya es conocido.

Ejemplos:

- Al crear un proyecto, el usuario entra automáticamente al proyecto recién creado.
- Al crear una sección, el usuario comienza a trabajar sobre esa sección.
- Al generar una narración, el resultado se presenta inmediatamente para su revisión.
- Al completar una exportación, el usuario accede directamente al resultado generado.

Cada acción representa una transición natural hacia el siguiente paso del proceso creativo.

La aplicación debe acompañar el trabajo, no interrumpirlo.

## La aplicación acompaña el proceso creativo

Narrador Studio no obliga al usuario a completar configuraciones complejas antes de comenzar.

Las decisiones avanzadas aparecen únicamente cuando realmente son necesarias.

El usuario puede empezar a trabajar con la menor cantidad posible de información.

La complejidad crece junto con el proyecto.

Nunca antes.

## Manifiesto

Narrador Studio existe para que las personas dediquen su tiempo a crear historias, no a aprender a usar una aplicación.

Cada decisión de producto debe reducir la fricción, respetar el proceso creativo y permitir que la tecnología desaparezca detrás del contenido.

Cuando exista una duda entre añadir una función o simplificar el flujo, Narrador Studio elegirá la simplicidad.
