Cada idea deberá ser validada antes de incorporarse al roadmap o a la filosofía oficial del proyecto.

# Idea 001

## Título

Captura rápida de ideas

## Problema observado

Durante la creación de un guion las ideas aparecen de forma desordenada.

Es frecuente recordar conceptos mientras se escribe, lo que obliga a interrumpir el flujo creativo para insertar texto, copiar, pegar o reorganizar contenido.

## Hipótesis

Antes de escribir una narración, el usuario necesita capturar pensamientos de forma rápida y reorganizarlos visualmente.

## Posible solución

Implementar un muro de ideas compuesto por tarjetas independientes.

Cada tarjeta representa una idea breve.

Las tarjetas pueden:

- crearse rápidamente;
- editarse;
- eliminarse;
- reordenarse mediante arrastrar y soltar.

Posteriormente pueden transformarse en secciones del proyecto.

## Beneficios esperados

- Reduce la fricción al capturar ideas.
- Evita perder inspiración.
- Favorece la organización antes de escribir.
- Se adapta a distintos tipos de contenido.

## Riesgos

Podría añadir complejidad innecesaria para usuarios que prefieren escribir directamente.

Será necesario validar mediante uso real.
